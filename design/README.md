# June & Bloom Design Assets & Specifications

This directory holds the design system rules, brand assets, and visual references for the June & Bloom Lifestyle Company website.

## Structure

- [DESIGN.md](./DESIGN.md): The complete design system specification, colour tokens, typography pairings, restraint rules (no dividers, no black text, single primary button per view), and layout standards.
- `brand/`: Drop the official **JB monogram SVG** (`jb-monogram.svg`), wordmark/ampersand candidates, and brand marks here. (Per `DR-02`, the JB monogram SVG is used verbatim and never redrawn or recoloured.)
- `photography/`: Owned photography for gift boxes (`4:5` portrait), charcuterie boards (`4:5` portrait), hero and sisters' story (`3:2` landscape), and holiday styling portfolio (`4:5` / `3:2`).
- `references/`: Moodboards, packaging references, and print layout references (packing slips, gift note cards).
